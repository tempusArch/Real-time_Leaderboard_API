# Real-time-Leaderboard-API

## Tech Stack
- C#
- .NET 8
- ASP.NET Core Web API
- EF Core
- PostgreSQL
- AutoMapper
- Redis

## Features
- JWT User Authentication and Role-based Authorization
- Admin management for Game, Season, Score, Leaderboard
- Redis sorted sets for real-time ranking, score updates and queries
- Archive finished seasons' leaderboard for score history tracking
- Global ExceptionHandler
